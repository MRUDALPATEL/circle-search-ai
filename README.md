# Circle Search AI

### AI-powered visual search for Windows

Draw around anything on your screen and instantly get answers, explanations, and context using AI.

</div>

---

## Overview

Circle Search AI brings a visual-first AI experience to the Windows desktop.

Instead of taking screenshots, opening browsers, uploading images, and describing what you're looking at, simply activate the app, draw around any content on your screen, and ask a question.

The application captures the selected region, analyzes it using AI vision models, and returns contextual answers in seconds.

---

## Why It Exists

Information is everywhere on our screens:

- Error messages
- Source code
- Charts
- Documents
- Products
- User interfaces
- Images

Most workflows require multiple steps to understand what you're looking at.

Circle Search AI reduces that process to:

```text
Select
↓
Ask
↓
Understand
```

---

## Key Features

### Global Activation

Launch from anywhere using a keyboard shortcut.

```text
Alt + Space
```

No matter which application is currently open.

---

### Freehand Selection

Draw around exactly what you want to analyze.

Unlike traditional screenshot tools, selections are not limited to rectangular regions.

---

### AI Vision Analysis

The selected content is analyzed using Gemini Vision.

The system can understand:

- Code
- Error messages
- Technical documentation
- Products
- Charts
- Diagrams
- Images
- User interfaces

---

### Context-Aware Questions

Ask questions about the selected content.

Examples:

```text
What is this?

Explain this error.

How does this code work?

Summarize this document.

What product is shown here?
```

---

### Follow-Up Conversations

Continue asking questions without creating a new selection.

This allows deeper exploration of the same content while maintaining context.
